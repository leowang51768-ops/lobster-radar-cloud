# 獨立關鍵分點追蹤：資料累積階段

固定沿用 `stock_universe.py` 的163檔；不改雷達買點、排序、停損、LINE或即時监控名單。

- 台灣時間週一至週五22:00執行。只接受已具163檔官方當日股價的日期；休市／上游未更新不冒用舊資料。
- 每檔保存當日個股買超／賣超各至多15家，包含名稱、原始分點識別、買進、賣出、淨額、成交比重、來源日期與採集時間。未上榜不是零交易。
- 各榜前三家加入歷史補抓佇列，每天最多60次近60日歷史請求，按最久未成功更新順序輪替。前三家只控制採集量，並非投資門檻。历史會按日期／股票／分點去重。
- 排行榜、逐日歷史、來源官方股價分開保存於 `branch_tracker/data/branches.sqlite`。不存網頁與圖片，不每日重建資料庫，不滾動刪除歷史證據。
- `status.json` 記錄163檔覆蓋率、缺漏、累積完整採集日數、筆數、容量；`coverage.csv` 是當日逐檔稽核。部分失敗仍保存成功資料，禁止宣稱完整。
- 遇403／429／驗證阻擋就停止該次來源抓取，不繞過限制。請求至少間隔1.5秒。

20個完整採集交易日後可先做資料品質複盤；40／60日持續觀察。這是檢視節點，不是能認定關鍵分點的保證，也不自動改雷達。

後續是否使用，須另評估每個股票／分點的有效且不重疊樣本、5／10／20交易日表現、基準報酬、選樣偏差、樣本外驗證與資料缺漏。今天發現的分點回填歷史有事後選樣偏差，不能當成當時已發出的訊號。回填60筆逐日紀錄不等於60筆獨立交易。

目前只採集，不標示關鍵分點、不輸出勝率、不發訊息。網站是第三方排行榜，不能代表全分點完整成交資料或識別背後客戶。原始張數有四捨五入；官方成交量是股，後續比率計算須換算。
