- 「轉賣」明確定義為前一交易日淨買進、當日淨賣出；連買遇到持平或賣超中止，五日視窗全買超顯示「連買5日以上」。
- LINE 每檔一行，例如 `🧩 籌碼：投信連買3日｜外資轉賣`。目前實際呈現順序為外資、投信。
- 現有來源沒有券商分點資料，故不計算或宣稱買盤集中、隔日沖、短線進出頻繁；此版本只啟用可核對的法人連續性。
- 可選 GitHub Secret `FINMIND_TOKEN` 用於授權；沒有設定時沿用公開 API，取不到資料不會偽裝成低風險。

### 保留候選與驗證

`chip_candidate_snapshots.jsonl` 保留所有掃描候選（包含缺資料、未入選者）的第一次當日快照、五日法人數字及當時排名。相同日期／股票／策略重跑不覆寫，歷史重播不建立冒充當時取得的快照。`selected_for_digest` 只代表當次選入，實際通知成功仍以原有 `line_pick_snapshots.csv` 為準。

`chip_candidate_outcomes.csv` 每日追蹤通知日之後第 1、3、5、10、20 個市場交易日；基準是假設隔天開盤價，觀察到期收盤報酬、是否收盤跌破突破價／停損及盤中觸及停損。這是未扣成本、未模擬停損成交的觀察報酬，不是實際交易績效或自動進場建議。缺股價不跳日補算。原本已發通知的績效資料維持原算法。

驗證：`python -m unittest discover -s tests -v`。測試使用假資料，不發送 LINE。
